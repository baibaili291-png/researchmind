## 一、行业背景

### 1.1 概念界定与统计口径

本报告讨论的对象存在两个层次的界定。狭义界定为"企业级 AI 智能体解决方案"，即以大语言模型和多智能体体系为核心、面向企业内部运营、管理与决策环节、提供可理解、可执行、可协作的智能任务代理服务的系统化方案 [E1]。广义界定为"AI Agent"，即以大模型为核心认知引擎，在无需持续人工干预的情况下自主感知、记忆、决策、交互与执行的智能系统 [E47]。

需要特别指出的是，统计口径在同一来源内部亦存在表述漂移：IDC 数据在部分文本中被表述为"中国企业级 AI 智能体市场规模达 212 亿元" [E5][E32]，在另一些文本中则被表述为"2025 年中国 AI 智能体市场规模已达 212 亿元" [E15][E52]，而该来源中确有"该市场统计口径表述为中国企业级 AI 智能体市场"的说明 [E49]。这一漂移直接影响读者对"企业级"与"全市场"边界的理解，是后文所有规模比较的前提约束。

### 1.2 发展阶段判断

行业阶段判断在多个来源中方向一致：企业级 AI Agent 在 2026 年正从技术概念进入规模化落地期，是当前确定性最高的数字化投入方向 [E7]；企业级 AI 智能体已正式迈入规模化落地周期，国内相关服务市场正经历结构性重塑 [E33]。这意味着讨论重心已从"是否可行"转向"以何种路径落地、由谁承接"。

### 1.3 技术演进脉络

从技术史看，2023 年 3 月开源项目 AutoGPT 以 GPT-4 为驱动基础发布，允许 AI 自主行动、完全无需用户提示每个操作 [E56]；2023 年 4 月斯坦福大学研究者首次创造了多个智能体生活的虚拟环境 [E57][E38]。此后技术重心逐步转向框架化与工程化，形成当前以 AgentScope、DeepAgents 为代表的框架竞争格局 [E25][E26][E27]。

### 2.3 需求结构与赛道分化

不同细分赛道的需求强度与盈利质量并不一致，呈现明显的"需求—利润"错配：

- **编程 Agent**：被描述为最健康的赛道，因为效果直接摆在代码里 [E8]。
- **客服 Agent**：需求最旺盛但利润最薄的赛道 [E9]。
- **知识库 Agent**：正在变成企业软件的"标配功能"，但独立厂商的空间在被云厂商挤压 [E10]。
- **个人知识助理**：Obsidian、Notion 等个人知识管理工具配上 Agent 插件，形成一个"个人知识助理"的新消费市场 [E11]。
- **强监管行业**：金融、医疗、法律这类强监管行业的 Agent 还是以"辅助人"为主，不敢直接"替代人" [E12]。

### 2.4 产业投入

资本端，高盛估计美国超大规模云厂商 2026 年资本支出合计逾 7,000 亿美元，中国逾 700 亿美元（均为高盛预测） [E23]。财务空间方面，中国云厂商资本支出占经营现金流的比例约为 60%，显著低于美国的约 90%，为 2026 年下半年至 2028 年的进一步扩张提供财务空间 [E24]。云基础设施份额方面，据 Gartner，阿里云 2025 年亚太 IaaS 市场份额升至 22.5%（2024 年为 20.8%），全球 IaaS 市场份额升至 7.7%（2024 年为 7.2%） [E22]。

## 三、竞争格局

### 3.1 供给端两分法：综合全栈 vs 垂直专精

IDC 最新数据显示，当前市场供给端已清晰分化为两大阵营：一类是具备完整技术栈、贯通算力与应用全链路的综合全栈厂商，另一类是深耕特定业务场景、具备深厚行业 Know-how 的垂直专精服务商 [E34][E50]。这一格局被概括为"综合巨头领跑、垂直标杆突围" [E36]；其内在机制是头部企业凭借技术与生态优势占据主导地位，而垂直领域企业凭借场景适配性赢得细分市场认可 [E37][E53][E54]。

### 3.2 平台三流派

从平台形态看，国内主流 AI Agent 平台被分为企业级智能体、开源框架智能体、个人办公智能体三大类别，并逐一解析其核心优势与适用场景 [E14][E51]。这一分类与供给端两分法互为补充：前者刻画交付形态，后者刻画能力边界。

### 3.3 开源与生态路径

开源框架路径的代表性做法是通过开源框架整合大模型能力、本地执行权限与技能生态 [E21]。这一路径与"开源框架智能体"分类 [E14] 相呼应，其竞争力来源在于整合能力而非单一模型能力。

### 3.4 下沉市场与轻量化服务

在中小商户侧，已有服务商凭借低成本、易操作的优势，成为中小商户私域运营的核心 AI 服务伙伴 [E55]。这与"个人办公智能体"这一轻量化类别 [E14] 及个人知识助理新消费市场 [E11] 共同构成需求的长尾部分。

### 3.5 跨界与国际动态

Meta 宣布收购 Moltbook，创始人团队并入 Meta 超级智能实验室，标志科技巨头正式入局 AI Agent 社交赛道 [E35]。该事件提示竞争边界正在从企业软件向社交与消费场景外溢。

## 四、技术路线

### 4.1 单智能体编排 vs 多智能体协作

当前技术路线之争的核心议题是单智能体编排与多智能体协作的取舍，AgentScope 与 DeepAgents 被作为该议题下的框架选型对比对象 [E27]。其中 AgentScope 由阿里巴巴通义实验室推出，承载中国顶尖 AI 实验室对多智能体系统的深度思考 [E25][E40][E41][E58]；DeepAgents 由 LangChain 团队打造，试图将 Claude Code 的成功模式产品化 [E26][E42][E43][E58]。两条路线的差异在于：前者指向多智能体系统的体系化探索，后者指向已被验证的开发范式的产品化复制。

### 4.2 产品创新方向

当前产品创新集中于四大方向：交互界面消隐化、多智能体协同、垂直场景深耕与架构轻量化 [E48]。这四个方向分别对应交付体验、系统架构、行业适配与部署成本，与前述"综合全栈 vs 垂直专精"的供给分化 [E34] 和"企业级/开源/个人"的流派划分 [E14] 在逻辑上相互印证。

### 4.3 强监管场景的技术约束

在金融、医疗、法律等强监管行业，Agent 仍以"辅助人"为主，不直接"替代人" [E12]。这一约束并不主要来自模型能力，而来自责任归属与合规边界：技术路线的选择必须与"人在回路"的组织形态匹配。

## 五、商业机会

**（1）B 端主战场。** B 端是驱动中国 AI Agent 市场增长的主体变量，长期贡献约九成收入 [E46]；企业级 AI Agent 被视为当前确定性最高的数字化投入方向 [E7]。这意味着资源应优先配置于企业内部运营、管理与决策环节 [E1]。

**（2）按赛道质量差异化配置。** 编程 Agent 因效果可直接体现在代码中而被描述为最健康的赛道 [E8]；客服 Agent 需求最旺盛但利润最薄 [E9]，适合以规模与效率取胜、不宜期待高毛利；知识库 Agent 已成本企业软件标配功能 [E10]，其价值更多体现在存量产品的功能补强而非独立品类。

**（3）垂直专精路径。** 在综合全栈厂商主导的格局下 [E34][E50]，垂直专精服务商的机会来自特定业务场景的行业 Know-how [E34] 与场景适配性 [E54]，尤其在强监管行业需以"辅助人"形态交付 [E12]。

**（4）长尾与个人市场。** 个人知识管理工具搭配 Agent 插件形成的"个人知识助理"新消费市场 [E11]，以及面向中小商户的低成本、易操作服务 [E55]，构成轻量化方向的机会池，并与"个人办公智能体"平台类别对应 [E14]。

**（5）开源生态位。** 通过开源框架整合大模型能力、本地执行权限与技能生态的路径 [E21]，为不具备全栈能力的参与者提供了另一种切入方式。

**（6）基础设施侧投入周期。** 中国云厂商资本支出占经营现金流约 60%、低于美国约 90% 的水平，为 2026 年下半年至 2028 年的进一步扩张提供财务空间 [E24]，意味着基础设施供给侧的投入周期尚未见顶。

## 六、风险分析

**（1）统计口径风险（首要风险）。** 同一市场存在 56 亿元 [E2]、212 亿元 [E5]、449 亿元 [E4]、591 亿元 [E29]、3320 亿元 [E18]、2.6 万亿元 [E44] 等多套数值，且"企业级"与"全市场"的表述在同一来源内亦不统一 [E5][E15][E49]。以此为基础做投资测算或目标设定，存在系统性高估或低估的可能。此外，部分原始表述存在数值截断 [E6]、来源日期标注为"未知"的情况，可追溯性不足。

**（2）赛道利润结构风险。** 需求最旺盛的客服 Agent 恰是利润最薄的赛道 [E9]，若按需求热度配置资源，可能出现"收入增长、毛利不增"的错配。

**（3）平台挤压风险。** 知识库 Agent 独立厂商的空间正在被云厂商挤压 [E10]；叠加头部企业凭技术与生态优势占据主导 [E37][E53]，独立厂商在标准化功能层面的生存空间持续收窄。

**（4）合规与替代边界风险。** 金融、医疗、法律等强监管行业的 Agent 仍以辅助人为主、不直接替代人 [E12]，"替代人力"叙事在此类场景中不成立，相关商业模型的定价基础需要重新设定。

**（5）投入差距风险。** 高盛估计 2026 年美国超大规模云厂商资本支出逾 7,000 亿美元、中国逾 700 亿美元（均为高盛预测） [E23]，绝对投入差距显著，可能影响长期算力供给与模型迭代节奏。

**（6）格局定型风险。** 供给端已"清晰分化"为两大阵营 [E34][E50]，市场亦呈现"综合巨头领跑、垂直标杆突围"的清晰格局 [E36]。对新进入者而言，可占据的空白位正在减少。

**（7）跨界竞争风险。** Meta 收购 Moltbook、创始人团队并入 Meta 超级智能实验室 [E35]，显示科技巨头可从社交等非企业软件场景切入 Agent 赛道，竞争边界具有不确定性。
